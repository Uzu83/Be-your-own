# 撮影ガイド

単語レベル MVP のためのクリップ撮影の目安。**質より枚数**。同じ語を少しずつ条件を変えて数多く撮ると精度が上がります。

## レイアウト

```
data/raw/
  あ/    あ_001.mp4  あ_002.mp4 ...
  い/    い_001.mp4 ...
  はい/  はい_001.mp4 ...
```

フォルダ名は `configs/words_ja.txt` の語と一致させる。

## 1 クリップの撮り方

- **長さ**: 1〜2 秒。発話の前後を少しだけ含める。
- **枚数**: 1 語あたり **最低 30、できれば 100+**。多いほど良い。
- **顔**: 正面〜やや斜め。口元がはっきり映ること。明るさを確保。
- **バリエーション**: 話速・照明・距離・背景・（可能なら）話者を変える。過学習を防ぐ。
- **フレームレート**: 25〜30fps を推奨（`extract.py` はフレーム単位で処理）。

## 撮影後

```bash
python -m lipreading.extract --input data/raw --output data/processed
python -m lipreading.train   --data  data/processed --config configs/base.yaml
```

## コツ

- 口元が切れる・暗いクリップは弾く（`extract.py` は顔未検出フレームを自動スキップ）。
- まず「あいうえお」5 語だけで一巡し、パイプライン全体が回ることを確認してから語を増やす。
